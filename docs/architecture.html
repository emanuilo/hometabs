Hometabs

Your personal agent in Telegram: a Claude Agent SDK agent that drives your Aside Browser, with your logins, through the aside MCP. Everything except Telegram and the model runs on your Mac.

Model
claude-sonnet-5-5 · effort medium by default, switchable with /model and /effort
Claude auth
ANTHROPIC_API_KEY (recommended), else CLAUDE_CODE_OAUTH_TOKEN, else the local Claude Code login
Agent tools
every aside MCP tool (mcp__aside: repl, memory_search, exec, …) + Skill (sign-in, 1Password)
Who can use it
User IDs in ALLOWED_USER_IDS

What happens when you send a message

How conversation history is kept

The bot itself stores no messages. Claude Code keeps the full history (your messages, its replies, every browser step and screenshot) in the running CLI process and writes it to a transcript file. The bot only remembers which transcript belongs to which chat.

Edge cases

/stop

Interrupts the running turn through the SDK and drops anything queued behind it. The reply ends with “(stopped)”.

/new

Closes the CLI for that chat and forgets its session id. The next message starts a fresh conversation.

Message while busy

You get “Queued”. It runs after the current turn, in order, unless /stop or /new comes first.

Bot restart

Messages sent while it was down are skipped. Conversations resume from sessions.json; a failed resume starts fresh.

Agent crash

You get the error text. The CLI is closed and respawned on your next message, resuming the same session.

/model and /effort

The choice is bot-wide and saved in .state/settings.json; the model list comes from Anthropic's /v1/models, cached in .state/models_cache.json. It applies from your next message, resuming the same session.

Skills

Rebuilt at every start in .state/plugin/: the bot's own sign-in skill plus Aside's 1password skill copied from your Aside install. A missing Aside skill is skipped with a warning.

Irreversible actions

The system prompt makes the agent ask you in chat before buying, sending, submitting, deleting or changing settings. It may sign in with 1Password autofill when a task needs it, but never types secrets from chat.
